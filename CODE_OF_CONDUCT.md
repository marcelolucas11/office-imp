# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todas as pessoas com respeito. Não são aceitos assédio, ataques pessoais,
discriminação de qualquer tipo nem a publicação de informações privadas de terceiros.
Críticas ao código são bem-vindas; críticas a pessoas, não.

Para relatar um problema de conduta, use o relato privado do GitHub (Security → Report a vulnerability)
ou fale com os mantenedores por uma issue marcada como `conduta`. Os relatos são tratados com sigilo.
